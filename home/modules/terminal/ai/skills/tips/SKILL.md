# Tips

Show the user this cheat sheet in Russian, as is. If they passed a topic, show only the matching
rows and say how to ask for them in their current task.

## Мои скиллы

| Когда | Что написать |
|---|---|
| Ухожу спать, пусть всё доделает | `/night-shift` (можно добавить ветку: `/night-shift integration/x`) |
| Много задач, нужно раздать по тредам | «ты оркестратор» — сработает `orchestrate` |
| Накидал аннотаций в превью | просто отправь их — сработает `annotations` |
| Вернулся и всё забыл | «что было сделано?» или «покажи картинками до/после» — `catch-up` |
| Страница «было / стало» по всей ветке, с картинками и меню | «сделай страницу с изменениями» — `changes-page` |
| Заполнить табель часов | `/timesheet` |
| Caspian: обновить тестовые серверы | «обнови тест сервер и av» — `deploy-test` |
| Прошлый разговор в новый тред | `/handoff` |
| Проверить план на прочность | `/grilling` |
| Хитрый баг | «diagnose» — `diagnosing-bugs` |
| Код-ревью ветки | `/code-review` |

## Возможности T3 Code, о которых легко забыть

| Что | Как попросить |
|---|---|
| Ввести токен или пароль, не светя его в чате | «запроси у меня токен» (`request_secret`) |
| Несколько картинок прямо в ответе | «пришли скриншотами» |
| Схема или график в чате | «нарисуй диаграмму» (`html_render`) |
| Видео, как агент проходит сценарий | «запиши видео, как …» (запись превью) |
| Android-эмулятор, смотреть в Device-панели | «поставь APK в эмулятор и проверь …» |
| Запуск по расписанию или webhook | «каждое утро в 8:00 делай …» (`schedule_task`) |
| Страница-отчёт со ссылкой, чтобы поделиться | «сделай страницу / artifact» |
| Найти старый тред | «найди тред, где мы обсуждали …» |
